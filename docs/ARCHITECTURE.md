## 二、Agent 协作体系

### 2.1 五 Agent 协作链

```
用户输入
  │
  ├─ Hermes Agent（意图识别）
  │    ├─ 推理模型优先（DeepSeek-V4-Pro / GLM-Z1）
  │    ├─ 指令模型降级（GLM-4-Flash）
  │    └─ 本地 fallback 兜底
  │
  ├─ Review Agent（质量审核）
  │    ├─ 脚本审核（video-review）— 5 项检查清单
  │    ├─ 参数审核（review）— chain-of-thought 推理
  │    └─ 结果审核（final）— 最终质量把关
  │
  ├─ Orchestrator（编排调度）
  │    ├─ 并行判断（sequential / parallel / hybrid）
  │    ├─ 动态调度（按依赖关系）
  │    └─ 重试回退（指数退避 1s→2s→4s，最多 3 次）
  │
  └─ 执行 Agent
       ├─ StoryWriter（故事创作 → 视频脚本）
       ├─ VideoMaker（参数提取 → 分镜生成，单段 ≤18 秒）
       └─ ImageCreator（图像参数 → prompt 优化）
```

### 2.2 Agent 上下文构建

每个 Agent 的上下文由以下层级组成：

```
System Prompt（角色 + 可用工具列表）
  ├─ 长期记忆（向量召回 top-3 相关经验）
  ├─ 短期记忆（会话内最近 10 轮对话）
  ├─ 其他 Agent 上下文（共享上下文快照）
  ├─ 任务历史（上一个任务的参数和结果）
  └─ RAG 知识（向量 + 关键词混合检索）
```

### 3.2 智能模型路由

4 级路由策略，6 维度自动决策：

| 复杂度 | 模型 | 场景 |
|--------|------|------|
| **simple** | 本地 RAG | 简单问答、关键词匹配 |
| **medium** | GLM-4-Flash (智谱) | 意图识别、参数提取、审核 |
| **complex** | DeepSeek-V4-Pro | 多轮上下文融合、深度推理 |
| **vision** | GLM-4V-Flash (智谱) | 多模态视觉理解 |

### 3.3 记忆系统

```
工作记忆 (Working Memory)
  └─ 当前对话上下文，实时可用

情景记忆 (Episodic Memory)
  └─ 历史交互记录，15 轮自动压缩，保留最近 5 轮

语义记忆 (Semantic Memory)
  └─ 向量化知识库（智谱 Embedding-2），余弦相似度检索

程序性记忆 (Procedural Memory)
  └─ 审核 Agent 自学习，记录用户修正，7 天有效期
```

## 五、数据流设计

### 5.1 图片生成流程

```
用户输入 → Hermes 意图识别 → 审核 Agent 检查
  → Orchestrator 调度 ImageCreator
  → 模型路由器选择引擎（Trae AI / 万相 / CogView-4 / 火山方舟）
  → imageService 调用 API → 审核 Agent 最终检查
  → 返回结果 → 可选：社交媒体自动发布
```

### 5.2 视频生成流程

```
用户输入 → Hermes 意图识别 → 审核 Agent 脚本审核
  → Orchestrator 调度 StoryWriter 生成脚本
  → VideoMaker 提取参数 + 分镜检测
  → 模型路由器选择引擎（Agnes / CogVideoX / Seedance / 万相 / LTX）
  → 长视频自动拆分 → 并行生成 → 拼接
  → 审核 Agent 最终检查 → 返回结果
  → 可选：办公平台通知 + 社交媒体自动发布
```

## 七、安全设计

- **JWT 鉴权**：白名单 + 路由守卫，auth 路由和静态资源免鉴权
- **高并发保护**：滑动窗口限流 + LLM 调用队列 + 熔断器 + 超时保护
- **配额管理**：按模型每日/总限额，防止 API 滥用
- **A2A 安全**：Bearer Token 认证，Agent Card 仅公开能力描述
- **社交媒体**：OAuth 2.0 授权，Token 本地加密存储
- **办公工具**：Webhook 方式，Token 环境变量管理
